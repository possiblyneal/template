# Documentation

## Purpose

Record decisions, cross-app contracts, and approved plans.

## Ownership

| When writing… | Put it in… |
|---|---|
| A decision and its rationale | `adrs/`. See Local Contracts for numbering and indexing. |
| A cross-app spec | `specs/`. Create the directory with the first spec. |
| A unit-specific spec | `apps/<name>/docs/specs/`. Change it in the same commit as the code. |
| A plan | `plans/`, set by `plansDirectory` in `.claude/settings.json`. Track it alongside the code for approval before implementation. |
| Research findings | `research/`. Keep one Markdown file per question, cite the primary sources, and name the probe environment where relevant. Record resulting decisions in an ADR or ticket answer. |
| Language selection guidance | `language-ranking.md`. Changing the supported set still requires an ADR. |
| An informal backlog item for this repository | `TODO.md`, not a generated repository's backlog. |

## Local Contracts

**ADRs:** Copy `adrs/0000-template.md`; replace all frontmatter and placeholders. Number from `0001` in one sequence across scopes.
Link an app's own `adrs/` from here if local decisions would drown out repo-wide ones. Supersede decisions with new records instead of rewriting history.

**ADR index:** Stage the index regenerated by `scripts/adr-index` with any changed record. The pre-commit hook rejects a stale index. Hand edits are overwritten.

- `adrs/index.md` lists `NNNN-…` records by `title`, `status`, and `superseded_by`, excluding `0000-template.md`. It is absent until the first record exists.
- `superseded_by` must resolve to an existing file, named relative to the repository root or by filename for a replacement in `adrs/`. The script performs no other frontmatter validation.

**Approved plans:** Preserve the body as approved. If a later rename, move, or reversal makes a plan stale, add a blockquote directly under its title pointing to the replacement.
Follow the annotated plans with `.openclaude/` paths rather than fixing their historical paths.

## Work Guidance

`.repo-template.json` marks `docs/` as product-owned. When changing the ADR format, update the payload's template as well as `adrs/0000-template.md` here.

For what the payload ships, read `apps/github-repository-template/docs/github_repository_structure.md`; keep the inventory there.

## Verification

`scripts/tests/adr-index-test` covers `scripts/adr-index`. The hook checks the derived index, not the prose. For prose changes, follow the closeout in `~/.claude/rules/documentation.md`.
